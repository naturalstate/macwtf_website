# Screenshots

Drop PNGs in here with these exact names and they appear on the CLI page
automatically. Until a file exists, the page shows a labelled placeholder in
its slot, so a missing screenshot is obvious rather than an empty gap.

| File | Shows |
|---|---|
| `01-profiles.png`  | The profile picker — the first screen, with the preview pane |
| `02-catalogue.png` | The category tree with a selection pinned at the top |
| `03-plan.png`      | The plan screen listing the commands that will run |
| `04-progress.png`  | A run in progress, with the progress bar |
| `05-report.png`    | The end-of-run report and the manual-steps checklist |

Anything roughly 2:1 to 3:2 works. Full terminal window is ideal; the page
scales them to the content width.
